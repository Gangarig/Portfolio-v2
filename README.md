# Minimal Portfolio

A clean, responsive personal portfolio built with plain HTML, CSS, and a small design system.

Focused on clarity, accessibility, and minimal design.

## ✨ Features

- Light / Dark theme toggle (saved in localStorage)
- Responsive layout (desktop → mobile)
- Minimal design system (tokens, themes, components)
- Project cards with hover interaction
- Downloadable CV
- Simple contact bar (Email / LinkedIn)

## 🛠 Tech Stack

- HTML5
- CSS3 (design tokens, CSS variables)
- Vanilla JavaScript

No frameworks. No build tools.
